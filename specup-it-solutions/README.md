# SpecUp IT Solutions Website

A modern, responsive website for SpecUp IT Solutions - a software development company specializing in web apps, mobile apps, systems, and custom software solutions.

## 🚀 Features

- **Modern Design**: Clean, tech-focused aesthetic with gradient accents and glassmorphism effects
- **Fully Responsive**: Mobile-first design that works seamlessly across all devices
- **Smooth Animations**: Powered by Framer Motion for engaging user experience
- **Performance Optimized**: Built with Next.js 14+ for optimal performance
- **TypeScript**: Type-safe code for better development experience
- **Tailwind CSS**: Utility-first CSS framework for rapid styling

## 📦 Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons

## 🎨 Sections

1. **Hero Section** - Eye-catching landing with animated gradient text and statistics
2. **Services** - Showcase of all services offered (Web Dev, Mobile Apps, Systems, etc.)
3. **About/Why Choose Us** - Company overview with key features
4. **Technologies** - Tech stack showcase with modern icons
5. **Portfolio** - Project showcase with beautiful gradient cards
6. **Testimonials** - Client feedback and reviews
7. **Contact** - Contact form and information
8. **Footer** - Comprehensive links and social media

## 🛠️ Installation

1. Navigate to the project directory:
```bash
cd specup-it-solutions
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 📝 Build for Production

```bash
npm run build
```

## 🎯 Customization

### Colors
The website uses a dark theme with blue and purple gradients. You can customize colors in the Tailwind classes throughout the components.

### Content
- Update company information in each component
- Modify services in `components/Services.tsx`
- Add real projects in `components/Portfolio.tsx`
- Update testimonials in `components/Testimonials.tsx`
- Change contact information in `components/Contact.tsx`

### Images
Add your own images to the `public` folder and reference them in the components.

## 📱 Responsive Breakpoints

- **Mobile**: < 640px
- **Tablet**: 640px - 1024px
- **Desktop**: > 1024px
